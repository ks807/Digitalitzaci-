Comandos básicos

Windows (CMD) Linux (bash) Qué hace
dir ls Lista el contenido de la carpeta
cd cd Cambia de carpeta
cd (sin nombre) pwd Muestra la carpeta actual
mkdir mkdir Crea una carpeta
copy cp Copia un archivo
move mv Mueve o renombra un archivo
del rm Borra un archivo
type cat Muestra el contenido de un archivo
cls clear Limpia la pantalla
tasklist ps Lista los procesos en ejecución
ipconfig ip a Muestra la configuración de red
