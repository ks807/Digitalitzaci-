WS_01
Sistemas Operativos

Introducción a los sistemas operativos: qué son, qué hacen por debajo y cómo se manejan desde la línea de comandos en Windows y en Linux.

Ver presentación Ver prácticas

RESUMEN_WS1

¿Qué es un sistema operativo?

Es el software que hace de intermediario entre el hardware y los programas. Reparte la CPU, la memoria y el disco entre las aplicaciones y ofrece al usuario una forma de controlar el equipo.

Qué funciones tiene

  • Procesos: decide qué programa usa la CPU y cuándo.
  • Memoria: asigna y protege la RAM de cada programa.
  • Ficheros: organiza los datos en carpetas y archivos.
  • Entrada/salida: maneja teclado, pantalla, red y discos con drivers.
  • Seguridad: controla usuarios y permisos.

Kernel y shell

El kernel es el núcleo: habla directamente con el hardware. La shell es la capa que usamos nosotros, y puede ser una terminal (CLI, con comandos) o un escritorio gráfico (GUI).

Windows y Linux

Windows usa CMD o PowerShell y rutas con barra invertida (C:\Users). Linux usa bash y rutas con barra normal (/home), y distingue entre mayúsculas y minúsculas.
