Bases de Datos

Introducción a las bases de datos relacionales y al lenguaje SQL, trabajando con DataGrip como herramienta.

RESUMEN_WS4

¿Qué es una base de datos?

Una colección organizada de datos que se gestiona con un sistema gestor (SGBD). En las bases de datos relacionales, los datos se guardan en tablas con filas y columnas.

Claves

La clave primaria identifica cada fila de forma única. La clave foránea apunta a la clave primaria de otra tabla y así se relacionan los datos.

Lenguaje SQL

  • SELECT consulta datos.
  • INSERT añade filas.
  • UPDATE modifica filas.
  • DELETE borra filas.
  • CREATE TABLE crea una tabla.

DataGrip

Es el entorno de JetBrains para trabajar con bases de datos. Sirve para conectarse, ejecutar los ficheros .sql y ver el resultado de las consultas.

SQL Commands

sql · alwaysdata

-- SELECT consulta datos
mysql> SELECT * FROM alumnos;

-- INSERT añade filas
mysql> INSERT INTO alumnos (nombre) VALUES ('Ana');

-- UPDATE modifica filas
mysql> UPDATE alumnos SET curso = 'DAM' WHERE id = 1;

-- DELETE borra filas
mysql> DELETE FROM alumnos WHERE id = 1;

-- CREATE TABLE crea una tabla
mysql> CREATE TABLE alumnos (id INT, nombre VARCHAR(50));
