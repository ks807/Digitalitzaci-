RESUMEN_WS3

Entrada y salida

Un programa recibe datos del usuario (readln()) y muestra resultados por pantalla (println()). Es la base de cualquier programa interactivo.

Variables y tipos

Las variables guardan datos con un tipo: Int para enteros, Double para decimales y String para texto.

Operar con datos

Con los operadores + - * / % se hacen cálculos con las variables y se guarda el resultado.

Condicionales

Con if, else if y else el programa elige un camino según una condición. La calculadora combina las tres ideas: leer, operar y decidir.
